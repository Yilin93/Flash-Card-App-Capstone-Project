# Flash-Card-App-Capstone-Project
Flashy is a French-to-English flashcard desktop app built with Python, Tkinter, and pandas. Each card shows a random French word, then automatically flips after 3 seconds to reveal the English translation. Click ✅ if you knew the word and it's removed from your deck, or ❌ to keep it in rotation. Progress is saved to words_to_learn.csv, so each session picks up with only the words you still need to learn.

Features: timed card flip, spaced-repetition-style word removal, persistent progress via CSV, custom Canvas-based UI

Techniques involved: Python, Tkinter, pandas DtaFrame
